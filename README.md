## Study and package scope

This repository preserves the r14 benchmark archive associated with the earlier manuscript title, *A Time-Locked Benchmark for CNA Record Maintenance: Predictability, Identity Dependence, and Temporal Drift*. It also mirrors r26 supplementary materials for the current EMSE manuscript, *A Time-Locked Benchmark for CNA Record Maintenance: Identity Dependence and Transfer Limits*. The r14 archive contains project-authored scripts and tests, protocol and provenance documentation, aggregate result tables, figure/table source data, and rights information. The benchmark measures deterministic changes in CNA affected-field record structure. It does **not** measure semantic affected-population expansion, exploitation, security risk, patch priority, or deployment benefit.

The r14 archive and the r26 supplementary materials exclude raw CVE List V5 and CISA KEV histories, upstream record text, row-level labels or predictions, complete per-record trajectories, case keys, model weights, private review material, credentials, and third-party dependency binaries.
