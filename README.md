## Study and package scope

This repository accompanies *A Time-Locked Benchmark for CNA Record Maintenance: Predictability, Identity Dependence, and Temporal Drift*. The archive contains project-authored scripts and tests, protocol and provenance documentation, aggregate result tables, figure/table source data, and rights information. It measures deterministic changes in CNA affected-field record structure. It does **not** measure semantic affected-population expansion, exploitation, security risk, patch priority, or deployment benefit.

The archive excludes raw CVE List V5 and CISA KEV histories, upstream record text, row-level labels or predictions, complete per-record trajectories, case keys, model weights, private review material, credentials, and third-party dependency binaries.
