# Time-Locked CNA Record-Maintenance Benchmark


This repository distributes the curated version 5.8.2 reproducibility package for the study **A Time-Locked Benchmark for CNA Record Maintenance: Predictability, Identity Dependence, and Temporal Drift**.


Download `release_public_v5_8_2_20260929_r11.zip` and extract it to access the project-authored scripts, tests, protocol, aggregate result tables, figure source data, provenance notes, and rights statement.


The package measures deterministic changes in CNA affected-field record structure. It does not claim to measure semantic affected-population expansion, exploitability, security risk, patch priority, or deployment benefit. Upstream CVE List V5 and CISA KEV histories, original record text, row-level labels and predictions, complete per-record trajectories, case keys, model weights, private review material, and credentials are not included.
